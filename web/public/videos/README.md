# Showreel video

Save your showreel here as **`showreel.mp4`** (or `showreel.webm`) and refresh. The "Watch Showreel" buttons on the
Home page will play it in a pop-up. No code change needed.

Tips: H.264 MP4, ideally under ~15 MB (compress it for the web), 16:9, with a clean intro that carries your own
branding. If there is no file here, the buttons fall back to the YouTube/Vimeo link in `lib/site.ts`
(`showreelEmbedUrl`), and if that is empty too they show "coming soon".
